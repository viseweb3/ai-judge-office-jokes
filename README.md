One funny line about office life, written for make.fun's "Make the AI Judge Laugh: Office Jokes" bounty ($5 in USDC, 1st place $1.54). The program writes the line to `/output/entry.txt`; the gate checks it is 1–200 UTF-8 characters, and an AI judge then compares the entries two at a time and picks the funnier one.

## The line

> Our office printer has been 'out of order' for three years — the only thing in this building with a job description it actually follows, and HR still won't promote it.

(167 characters. The printer has been broken for three years, which makes it the only thing in the building that actually sticks to its job description — and HR still won't promote it. The one "employee" doing exactly what it was hired to do gets nothing.)

## Run it

```sh
node main.ts
```

Requires Node 22.18+ (the grader runs Node 22.23.4, which runs TypeScript as-is). It writes the line to `/output/entry.txt` and prints it.
